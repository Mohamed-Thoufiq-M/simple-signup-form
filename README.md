# Simple Sign-Up Form UI

A clean and minimalist sign-up form design created as part of my web development learning journey.

## ✨ Features
* Responsive UI Design
* Custom Gradient Background
* Styled Input Fields (Email, Name, Password)
* Modern Submit Button with Hover Effects

## 🛠️ Technologies Used
* **HTML5** - For the structure of the form.
* **CSS3** - For styling, colors, and layout.

## 🚀 How to view
You can simply download the files and open `index.html` in any web browser.
